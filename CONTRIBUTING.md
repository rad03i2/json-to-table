# Contributing / المساهمة

Contributions are welcome. Create a focused branch, add tests for behavioral changes, run `pytest -q`, and open a pull request describing the problem and solution. Keep dependencies minimal and never commit secrets or generated environments.

المساهمات مرحب بها. أنشئ فرعًا مخصصًا، وأضف اختبارات لأي تغيير سلوكي، وشغّل `pytest -q` ثم افتح Pull Request يشرح المشكلة والحل. حافظ على أقل عدد ممكن من الاعتماديات ولا ترفع الأسرار أو البيئات المولدة.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
